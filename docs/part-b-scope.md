# Part B 范围与状态

PDF Part B 是功能依据。移动端入口为 Agent / 语音 / 我的，我的包含历史与待办。

| 要求                | 当前实现与证据                                                      | 验收边界                                    |
| ------------------- | ------------------------------------------------------------------- | ------------------------------------------- |
| 网页与 Node.js 后端 | Next.js API，PostgreSQL迁移，生产构建通过                           | 本次新增代码尚未部署线上                    |
| 语音或文字录入      | 本机音频持久化/恢复、原音重试转写、无文字保存私有原音；真实文字闭环 | 真人手机、正式站ASR需另验收                 |
| 摘要与待办          | 真实Qwen工具循环、持久追问、上下文授权、真实数据库写入              | 不提供主动推送提醒                          |
| 至少两个工具        | create_todo / search_notes / list_todos；另有ask_clarification                   | 调用过程及证据可见                          |
| Free每天10次        | 原子预占、业务幂等、并发/恢复测试，真实HTTP第11次429                | 一次指逻辑整理/Agent任务；ASR有独立启动限制 |
| 历史问答及来源      | 录音时间过滤、实体保留、有限同义词、不同报价消歧                    | 无通用向量检索或用户偏好记忆                |
| 后台恢复            | 响应后启动、独立Worker、密钥调度接口、指数退避                      | 生产必须实际配置独立调度                    |
| README与配置        | 启动、关键取舍、环境模板、Worker及评估命令                          | 需对目标库执行001–005迁移                   |
| ≤3分钟演示          | work/nota-part-b-demo.webm，真实模型文字输入，约46秒                | 合成账户、本地数据库，无真人ASR验收声明     |
| 效果评估            | 87项本地检查；真实固定13场景14轮全部通过；可比较报告                | 只证明固定样本和指定断言                    |

详细保证和未实现范围见 [Part A 对齐说明](part-a-alignment.md)，证据见 [验证记录](verification.md)。
