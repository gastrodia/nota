# 设计决策

## 用户已确认

- Next.js / Vercel / Neon；语音 qwen3-asr-flash-realtime，文本 qwen3.8-flash。
- 移动端 Agent / 中央语音按钮 / 我的；语音按钮打开浮窗并开始录音，我的恰好历史、待办两个 Tab。桌面保持手机宽度。
- 参考图片仅提供奶油底色、深棕描边、柔和配色、像素图标的视觉参考；功能依据 PDF Part B。
- 用户授权开始后端、原件保存、轻量检索实现，自行配置密钥。

- 本地开发使用大陆百炼配置；Vercel文本使用香港工作空间，语音使用独立的新加坡工作空间Key与端点。两套环境独立维护，不从本地环境变量批量覆盖线上。

## 首版工程默认值

以下是实现采用的默认策略，可调整，不冒称逐项获得用户业务确认。

- 邮箱密码与数据库 opaque Session；14 天到期、退出可撤销。首版无邮件验证与找回密码。
- 上海时区每日 10 次 AI 任务；提交事务预占，没写入成功副作用的失败退还；已创建待办时保留扣次，原任务重试不重复工具。
- 每段录音 60 秒、原件最多 4 MiB；本机 IndexedDB 按账户保留原音，支持先保存云端原音及失败后重新转写。删除队列由请求及后台 Worker 清理。
- 云端优先实时 ASR，普通 Next 本地服务显式录后转写降级；真实音频和 PCM 分开处理。
- 工具为创建待办、查历史；明确请求/承诺才执行，否定/引用/设想不执行。缺少明确时刻时设空，不臆造提醒时间。模糊时间通过持久化追问补齐，明确无截止时间可以设空；没有主动推送提醒。
- 不引入向量库：账户内实体关键词、有限同义词和录音时间过滤；不同报价先澄清。词典之外的语义召回仍有限，需真实评估再决定 embedding。
- 每任务最多六轮工具决策、五次执行尝试；持久化游标与工具账本，通过租约/fence 恢复。响应后执行、独立 Worker 或密钥调度接口启动恢复；生产需配置其中一种独立调度。
- 明示访客示例、联调测试；固定替身用于协议验证，不用于宣称 Qwen 效果。

协议依据与验收边界见 README、audio-recording.md 和 verification.md。

## 联调修正

- 创建待办前独立验证用户是否授权该行动；工具默认拒绝未获授权的写入。笔记保存由系统完成，不通过待办工具代替。
- 原音支持Private Blob读写Token与OIDC；配置并存时显式选择私有Token。
- 语音与文本可使用独立Key和地域端点。空的ASR Key回退文本Key；上游无type的错误包也立即按失败处理。

- 大陆ASR联调后将Vercel函数固定在hkg1，以缩短与当前模型和存储的跨区距离；客户端等待实时连接上限30秒。

- ASR上游建连阶段允许一次重试，最多两次尝试；开始发送音频后不自动重连，避免重放。网络诊断仅记录非敏感错误信息。

本次对齐的完整保证与未实现范围见 [Part A 对齐说明](part-a-alignment.md)。
